# 智序 · 后台管理需求

本文描述 `smart-blog` 当前已经实现的后台管理模块，作为单独的需求基线。范围只包括管理员登录后的站点管理工作台，不包括前台首页、文章阅读、留言板和日记浏览的页面设计。

后台是管理员维护公开内容、审核互动和管理账号的工作区。前台负责展示，后台负责写入和审核。

## 1. 角色与访问

### 1.1 角色

| 角色 | 判定 | 能力 |
| --- | --- | --- |
| 管理员 | 角色值为 `0`，或用户名是 `admin` | 可以进入全部后台页面 |
| 普通用户 | 角色值为 `1` | 不能进入后台 |
| 未登录 | 会话中没有登录用户 | 不能进入后台 |

新注册账号固定为普通用户，状态为正常。

### 1.2 访问控制

除 `/admin/login` 外，所有 `/admin/**` 请求都要经过服务端拦截，不能只靠前台隐藏入口。

- 未登录访问后台，重定向到 `/admin/login`。
- 已登录但不是管理员，重定向到 `/admin/login?denied=1`，并提示「当前账号没有后台权限」。
- 后台登录接口使用 `adminOnly` 校验。普通用户即使密码正确，也提示「没有后台权限」，并记一条失败日志。
- 账号状态为锁定时不能登录，提示「账号已锁定」。

### 1.3 登录与退出

后台登录页为 `/admin/login`。

必填项：用户名、密码、验证码。验证码为图片，点击可刷新。校验失败时留在登录页并显示原因。

登录成功后：

- 更换会话标识，把用户写入会话。
- 更新最后登录时间、登录 IP 和登录次数。
- 写入一条成功的登录日志。
- 进入 `/admin`。

顶栏提供「前台」和「退出」。退出必须使用 `POST /logout`，并带回跳地址 `/admin/login`。不能改成 GET。

密码以 MD5 保存。登录时比对的是提交密码的 MD5，不保存明文。

## 2. 信息架构

登录后使用左侧导航加顶栏。当前页导航项高亮。

| 导航 | 路径 | 作用 |
| --- | --- | --- |
| 总览 | `/admin` | 站点数量和当前登录信息 |
| 文章 | `/admin/articles` | 文章列表、公开状态、热门、编辑 |
| 公告 | `/admin/notices` | 公告编写和置顶 |
| 评论 | `/admin/comments` | 评论审核和删除 |
| 留言 | `/admin/messages` | 留言审核、回复和删除 |
| 日记 | `/admin/diaries` | 日记编写 |
| 栏目 | `/admin/categories` | 栏目和标签 |
| 友链 | `/admin/links` | 友情链接 |
| 用户 | `/admin/users` | 锁定、解锁和改角色 |
| 登录日志 | `/admin/logs` | 查看登录记录 |
| 设置 | `/admin/settings` | 站点与阅读开关 |
| 个人信息 | `/admin/profile` | 资料和密码 |

顶栏显示当前昵称（没有昵称时显示用户名）、第几次登录、返回前台和退出。

有待审核留言时，侧栏「留言」显示提示点。待审核数量按状态 `0` 统计。

写操作一律使用 POST。成功或失败后回到原列表或原表单，并用一次性提示说明结果。

## 3. 总览

路径：`/admin`。

展示真实统计，不使用写死的数字：

- 文章总数。
- 评论总数。
- 友链总数。
- 文章访问量合计。
- 公开文章篇数。
- 已通过的顶层留言条数。
- 当前用户上次登录时间和登录 IP。第一次登录时说明这是第一次。
- 运行环境：Java 版本、操作系统、数据库名。

总览只读，不在这一页修改内容。

## 4. 文章

### 4.1 列表

路径：`/admin/articles`。每页 10 条，可按标题搜索。

列表需要能完成：

- 打开新建页 `/admin/articles/edit`。
- 打开编辑页 `/admin/articles/edit?id={id}`。
- 切换公开和私密。公开值为 `1`，私密值为 `0`。
- 设置或取消热门。热门值为 `1`。
- 删除文章。

公开文章才会出现在前台列表和详情。私密文章前台不可见。热门用于前台热门推荐。

### 4.2 编辑

新建标题为「写文章」，已有文章标题为「编辑文章」。

字段：

| 字段 | 规则 |
| --- | --- |
| 标题 | 必填，保存时截断到 255 字 |
| 栏目 | 必选，且栏目必须存在 |
| 标签 | 多选。选项随所选栏目过滤。保存为逗号分隔的标签名，最长 255 字 |
| 摘要 | 可空。为空时按正文自动生成 |
| 正文 | 必填，使用 Markdown |
| 公开 / 私密 | 单选。未指定时按公开保存 |
| 热门 | 可选 |
| 封面 | 可选图片。不上传则保留原封面 |

保存规则：

- 新建时记录作者、创建时间，访问量和点赞从 0 开始。
- 更新时记录更新时间，不重置访问量和点赞。
- 文章不存在、栏目不存在、标题或正文为空时，回到编辑页并提示原因。
- 保存成功后回到文章列表，提示「文章已保存」。

封面只接受 `jpg`、`jpeg`、`png`、`gif`、`webp`，单文件上限 5MB。文件存到上传目录，页面使用 `/uploads/` 路径。

## 5. 栏目与标签

路径：`/admin/categories`。栏目和标签在同一页维护。

栏目：

- 名称必填，1 到 30 个字符，不能与已有栏目重名。
- 栏目下仍有文章时不能删除，提示「栏目下还有文章，不能删除」。
- 删除栏目时，同时删除该栏目下的标签。

标签：

- 必须选择已存在的栏目。
- 名称必填，1 到 30 个字符。
- 可以单独删除标签。删除标签不删除已经写在文章上的标签文字。

## 6. 评论

路径：`/admin/comments`。每页 12 条，可按状态筛选。

评论状态：

- `0`：待审核或隐藏。
- `1`：已通过。前台文章页只显示已通过评论。

操作：

- 通过：状态改为 `1`，并把对应文章标为已有评论。
- 隐藏：状态改为 `0`。
- 删除：物理删除该条评论。

列表显示评论所属文章标题。文章已经不存在时，显示「文章已删除」。

评论是否先审后发，由站点设置「评论先审后发」决定。关闭时，前台新评论直接为已通过。

## 7. 留言

路径：`/admin/messages`。每页 12 条，按时间倒序。

筛选：全部、待审核、已通过、已驳回。

| 状态值 | 含义 |
| --- | --- |
| `0` | 待审核 |
| `1` | 已通过 |
| `2` | 已驳回 |

操作：

- 通过：仅非已通过的留言可执行，状态改为 `1`。
- 驳回：状态改为 `2`。驳回后的留言不能作为前台回复对象。
- 回复：保存回复内容，并把该留言标为已通过。
- 删除：删除该留言，并删除以它为父级的回复。

审核和删除后留在当前页码和当前筛选。回复成功后回到留言列表。

前台展示规则与后台状态一致：访客只能看到已通过留言；留言作者还能看到自己待审核的留言；管理员在前台还能看到全部待审核留言。已驳回留言不在前台展示。

同一 IP 30 秒内不能连续提交留言。这条限制在前台提交时生效，后台不提供绕过开关。

## 8. 日记

路径：`/admin/diaries`。同一页包含列表和编辑表单。带 `id` 时载入对应日记，否则是新建。

字段：

- 标题：必填，最长 100 字。
- 内容：必填，最长 2000 字。
- 心情：可选，最长 20 字。

新建时写入创建时间。保存成功提示「日记已保存」。可以删除。

前台日记列表展示这里保存的日记。日记没有独立详情页，前台点击后进入日记列表。

## 9. 公告

路径：`/admin/notices`。同一页包含列表和编辑表单。

字段：

- 标题：必填，最长 100 字。
- 内容：必填，最长 2000 字。
- 置顶：`1` 为置顶，未勾选时为 `0`。

列表按置顶优先，其次按编号倒序。可以删除。

公告没有独立的前台详情页。首页只展示有限条公告标题和摘要，不提供虚构的详情链接。

## 10. 友链

路径：`/admin/links`。同一页包含列表和编辑表单。

| 字段 | 规则 |
| --- | --- |
| 站点名 | 必填，不超过 15 个字符 |
| 站点地址 | 必填，不超过 45 个字符，必须以 `http://` 或 `https://` 开头 |
| 站点描述 | 必填，不超过 45 个字符 |
| 排序 | 可空，空则按 0。列表按排序和编号升序 |

可以编辑和删除。前台友链页展示这里保存的链接。

## 11. 用户

路径：`/admin/users`。每页 12 条，可按用户名或昵称搜索。

列表显示：用户名、昵称、角色、状态、手机号、登录次数。

角色名称：

- 用户名为 `admin`，或角色为 `0`：管理员。
- 其他：普通用户。

状态名称：`0` 为已锁定，其他为正常。

操作：

- 锁定和解锁。不能锁定当前登录账号，提示「不能锁定当前登录账号」。
- 修改角色，可选管理员或普通用户。不能修改当前登录账号的角色。不能修改用户名 `admin` 的角色。

后台不提供新建用户。新用户来自前台注册，且仅在「开放注册」开启时可以注册。

## 12. 登录日志

路径：`/admin/logs`。每页 15 条，按时间倒序，只读。

每次登录尝试都记一条日志，包括验证码错误、账号或密码错误、账号锁定、没有后台权限和登录成功。日志至少能区分账号、结果和说明。

日志页不提供删除和导出。

## 13. 站点设置

路径：`/admin/settings`。保存后回到本页，提示「设置已保存」。

| 设置项 | 规则 |
| --- | --- |
| 站点名 | 最长 40 字 |
| 副标题 | 最长 80 字 |
| 页脚 | 最长 80 字 |
| 关于 / 阅读说明 | 可多行，用于前台关于页 |
| 前台每页文章数 | 必须是数字，否则按 6 保存 |
| 显示阅读量 | 开关，默认开启 |
| 允许评论和留言 | 开关，默认开启。关闭后前台不能再发表 |
| 评论先审后发 | 开关，默认关闭 |
| 管理员留言免审核 | 开关，默认开启。管理员留言可直接通过 |
| 开放注册 | 开关，默认开启 |

未勾选的开关保存为关闭。页面上的默认勾选要和「未设置时视为开启」的项保持一致。

## 14. 个人信息

路径：`/admin/profile`。

资料：

- 昵称，保存时截断到 32 字。
- 手机号可空。填写时必须是 11 位数字。
- 头像可选。格式与文章封面相同。不上传新头像时保留原头像。

密码：

- 必须填写原密码和新密码。
- 原密码不正确时拒绝修改。
- 新密码至少 6 位。
- 修改成功后当前会话中的密码同步更新，不强制退出。

前台导航里的「个人资料」也指向 `/admin/profile`。普通用户点开会被拦截器挡回后台登录页，这是权限结果，不是另做一个前台资料页。

## 15. 通用规则

- 所有新增、修改、删除、审核、锁定、改角色、改设置、改密码和退出都使用 POST。
- 权限以服务端拦截和登录校验为准。菜单隐藏不能代替权限判断。
- 业务校验失败时给出明确中文提示，不展示堆栈。
- 列表分页使用已有分页数据，不在页面里重复请求同一份列表。
- 上传失败时提示「图片保存失败」或格式不支持，不写入半截文件路径。
- 删除是物理删除。删除留言时连带删除它的回复。删除栏目前必须先清空文章。
- 不在后台增加未实现的能力，包括 AI 助手、待办计划、日记隐私开关、公告详情页和批量导入。

## 16. 验收

1. 未登录访问任一后台页面，进入后台登录页。
2. 普通用户登录后台，被拒绝并留下失败日志。
3. 管理员登录后进入总览，数字与数据库一致。
4. 文章可以新建、编辑、公开、私密、设热门和删除；私密文章不出现在前台。
5. 有文章的栏目不能删除；空栏目删除后，其标签一并删除。
6. 评论可以通过、隐藏和删除；只有已通过的评论出现在前台文章页。
7. 留言可以按状态筛选、通过、驳回、回复和删除；驳回内容不出现在前台。
8. 日记、公告、友链的长度和地址校验与本文一致。
9. 不能锁定自己，不能修改自己的角色，不能修改 `admin` 的角色。
10. 设置项保存后，前台评论、留言、注册和阅读量表现与开关一致。
11. 退出使用 POST，并回到后台登录页。
12. 直接请求后台接口时，未登录和非管理员仍然被拒绝。
