# 智序 smart-blog 需求规格说明书 v2（现代化改造版）

> 版本：v2.0（2026-11-12）
> 基线：docs/需求规格说明书.md（v1 基线，2026-10-29）
> 定位变更：课程设计级博客 → **个人技术博客 + 面试展示全栈项目**

## 1. 项目概述

### 1.1 改造目标

| 维度 | 现状（v1） | 目标（v2） |
|---|---|---|
| 后端 | Spring Boot 2.7.18 / Java 8 / Thymeleaf 服务端渲染，无 REST API | Spring Boot 3.5 / Java 21 / REST API（JWT），Thymeleaf 层过渡期保留、验收后移除 |
| 前端 | 27 个手写 Thymeleaf 页面 + 手写 CSS（纸感莫兰迪） | Nuxt3 SSR + TypeScript + Tailwind（现代科技风、暗色优先） |
| 安全 | MD5 无盐、弱找回密码、无 Spring Security、明文 DB 口令 | BCrypt、Spring Security + JWT 双令牌、邮箱验证码找回、secrets 环境变量化 |
| 数据 | 时间 CHAR(19)、标签逗号文本、无迁移管理 | DATETIME、标签多对多关联表、Flyway 版本化迁移、索引设计 |
| 新能力 | — | 作品集、AI 摘要/相关推荐、友链申请、RSS/OG/sitemap/JSON-LD、⌘K 搜索 |
| 工程 | 2 个单测、无 CI、无 Docker、README 空壳 | 测试体系、Docker 化、commitlint、AGENTS.md 工程约束（远程 CI/CD 与服务器部署在本地验收通过后另起阶段） |

### 1.2 角色定义

| 角色 | 说明 | 能力 |
|---|---|---|
| 游客 | 未登录访客 | 浏览全部公开内容、搜索、点赞（浏览器去重）、提交留言/友链申请（限流+审核） |
| 注册访客 | 本地注册账号（保留 v1 注册体系） | 游客能力 + 评论/留言绑定账号身份、头像昵称 |
| 管理员 | role=0 | 全部后台能力：内容管理、审核、用户管理、站点设置 |

> v1 的访客注册/登录/用户管理保留（用户明确要求），但安全机制全部重做；不做 GitHub OAuth（访客未必有 GitHub）。

### 2.3 删除/降级（相对 v1）

| 项 | 处理 | 理由 |
|---|---|---|
| 手机号直接改密 | 删除，改邮箱验证码（SMTP 可配置；未配置时走管理员重置） | 高危漏洞（知道手机号即可接管账号） |
| `username=="admin"` 硬编码特权 | 删除，仅按 role 判定 | 越权风险 |
| MD5 密码 | Flyway 迁移期自动升级为 BCrypt | 安全 |
| 归档页/标签云独立页 | 不做（用户未选） | 标签筛选保留在文章列表页 |

## 4. 功能需求与验收标准（关键项）

### 4.1 首页
- Hero 区：品牌名 + 一句话定位 + 打字机副标题 + CTA（阅读文章/查看作品集）
- 最新文章 4 条（卡片）、精选作品集、公告置顶展示、页脚含 RSS/备案占位
- **验收**：SSR 首屏直出内容；亮/暗主题切换无闪烁；窄屏（<640px）单列不破版

### 4.2 文章列表
- 分页、标题/摘要/正文搜索、栏目筛选、标签筛选、热门榜
- **验收**：筛选条件组合正确；空结果有友好空态；分页保持筛选条件

### 4.3 文章详情
- Markdown 渲染（XSS 转义保留 v1 策略）、Shiki 亮/暗双主题高亮、TOC 滚动联动、阅读进度条、阅读时长、浏览量（Redis 缓冲落库）、点赞（浏览器指纹去重）、上一篇/下一篇、相关推荐、AI 摘要卡（已生成时显示）、评论区
- **验收**：代码复制按钮可用；草稿/下线文章对游客 404；浏览量刷新去重（同一浏览器会话）；JSON-LD 文章结构化数据通过校验

### 4.4 留言板
- 楼中楼回复、未登录可留言（昵称+限流）、登录用户绑定身份；先审后发开关生效
- **验收**：未登录 30s/IP 限流（Redis 实现不可伪造）；含 URL/敏感词被过滤并提示；自己的留言可删

### 4.5 作品集
- 卡片：名称、一句话简介、技术栈徽章、封面、仓库/演示链接、精选标
- **验收**：后台增删改排序实时生效；精选项出现在首页

### 4.6 AI 摘要
- 发布文章时异步请求 LLM 生成 100~150 字摘要 + 3 个相关文章推荐（基于标签/栏目打分兜底）
- **验收**：未配置 LLM 时发布流程不受影响，详情页不显示 AI 卡；后台「重新生成」按钮可用；LLM 超时（10s）不阻塞

### 4.7 友链申请
- 前台表单：站名/URL/描述；提交进待审（IP 限流 1 条/小时）
- **验收**：后台通过后出现在友链列表；拒绝时可填理由

### 4.8 站点设置
- 站名/页脚文案/关于页内容/分页大小/评论开关/留言开关/注册开关，Redis 缓存 + 修改即失效
- **验收**：修改后前台 5s 内生效（缓存失效）

### 4.9 认证（重做）
- 注册：用户名+密码+昵称；BCrypt 存储；注册开关可关
- 登录：验证码（可选开关）+ Redis 限流（5 次/15 分钟/IP）；JWT access(2h)/refresh(7d) 双令牌，refresh 可轮换
- 找回：邮箱验证码（SMTP 配置存在时）；未配置 SMTP 时由管理员在后台重置
- **验收**：明文/MD5 旧口令首次登录自动升级 BCrypt；连错 5 次锁定 15 分钟；JWT 过期后 refresh 静默续期，refresh 失效跳登录

## 5. 非功能需求

| 项 | 标准 |
|---|---|
| 性能 | 文章列表/详情接口 P95 < 200ms（本地）；Lighthouse Performance ≥ 90 |
| 安全 | OWASP Top10 常见项：注入（参数化）、XSS（转义+CSP）、越权（接口级鉴权）、弱口令（BCrypt cost≥10）、暴力破解（限流+锁定） |
| SEO | SSR 直出、语义化标签、OG/JSON-LD/sitemap/robots 齐全 |
| 可访问性 | 键盘可达、焦点回返、aria 标注、`prefers-reduced-motion` 遵循（沿用 v1 好底子） |
| 兼容 | 移动端断点 <640px 不破版；Chrome/Edge 最新两个大版本 |
| 工程规范 | Java 代码遵循 knowin-workspace 强制规范（阿里黄山版基线+项目补充，见仓库根 AGENTS.md）；前端遵循组件交互七态（键盘/焦点/空/加载/错误/窄屏/明暗） |
| 验证纪律 | 构建通过 ≠ 验收；浏览器实测窄屏与明暗主题；不凭空填写通过结果 |

## 6. 边界（明确不做）

- 不做：AI 助手、任务看板、日记私密开关、公告/日记详情页（沿用 v1 边界）
- 不做（本期）：GitHub 远程推送、CI/CD 流水线、服务器部署——本地验收通过后另起阶段
- 不做：访客 GitHub OAuth、归档独立页、多租户/多博客

## 7. 全链路验收场景

1. `docker compose up` 起 MySQL/Redis → 后端启动（Flyway 迁移自动执行）→ Nuxt 启动
2. 游客访问首页/列表/详情/留言板/日记/友链/作品集 → 全部 SSR 正常
3. 注册访客 → 登录 → 评论（待审）→ 管理员后台审核通过 → 前台可见
4. 管理员发文（配图上传）→ AI 摘要生成（或降级）→ 前台详情可见 → 浏览量/点赞变化 → Redis 定时落库
5. 游客提交友链申请 → 后台通过 → 前台友链出现
6. 管理员修改站点设置 → 前台 5s 内生效
7. 暗色/亮色 × 桌面/移动四象限逐页截图核对
