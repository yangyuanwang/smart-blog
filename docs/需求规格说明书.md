## 1. 产品概述

### 1.1 定位

智序是一个面向个人的数字工作空间，把公开写作、日常记录、留言交流和站点管理放在同一套系统里。

对外呈现为：现代、轻量的产品门户，而不是传统企业后台模板，也不是普通博客主题。对内管理仍使用独立的后台工作台，只对管理员开放。

产品同时承担三件事：

1. **门户**：首页说明这个空间能做什么，并把读者带到真实内容。
2. **知识空间**：博客、日记、友链、关于、留言。
3. **管理工作台**：文章、公告、评论、留言、日记、栏目、友链、用户、登录日志和站点设置。

### 1.2 目标用户

| 角色 | 说明 |
| --- | --- |
| 访客 | 未登录。可以阅读公开内容、查看友链和关于、提交留言（需验证码）。 |
| 普通用户 | 注册用户，角色值为 `1`。可以登录、留言、删除自己的留言；不能进入后台。 |
| 管理员 | 角色值为 `0`，或用户名恰好为 `admin`。可以使用全部前台能力，并进入后台。 |

### 1.3 产品边界

当前系统是「内容站点 + 管理后台」。

以下能力**没有实现**，需求上不得描述成可用功能：

- 对话式 AI 助手、智能芯片工作台、自动写作。
- 面向访客的独立「业务工作台」或任务看板。
- 日记之外的「计划 / 待办」模块。
- 日记的公开 / 私密开关。现有日记只要写入，前台就会展示。
- 公告详情页、日记详情页。
- 备案号配置界面。只有设置表里已经手工写入 `beian` 或 `icp` 时，页脚才会显示。

文章阅读页上的「智能」能力是有的，范围仅限：Markdown 渲染、自动摘要、阅读时长、关键词、相关阅读。详见第 8 章。

## 2. 运行与访问

### 2.1 环境

- 服务端口默认 `8080`。
- 数据库为本地 MySQL，库名 `blog`。
- 字符编码 UTF-8。
- 会话使用 Cookie，不在 URL 上携带会话标识。
- 上传目录由配置项 `blog.upload-dir` 决定，默认 `uploads`。单文件上限 5MB，整个请求上限 6MB。
- 启动时执行 `schema.sql`，只做「表不存在则创建」，不删除已有数据。

### 2.2 全局对象

每个页面都可以使用：

| 名称 | 来源 | 用途 |
| --- | --- | --- |
| `site` | 设置表全部键值 | 站点名、关于、页脚、开关 |
| `loginUser` | 会话 | 当前登录用户，未登录为空 |
| `pendingMessages` | 留言表 | 待审核留言数量，后台留言菜单用来显示红点 |

## 3. 信息架构

### 3.1 前台导航

桌面端顶部高度约 72px，粘性定位。从左到右：

- 左侧品牌：标志 +「智序 · Smart ERP」+ 辅助文字 `SMART WORKSPACE`。点击回到首页。
- 中间：首页、博客、留言、日记、友链、关于。当前页有明确激活态。
- 右侧：
  - 未登录：登录。
  - 已登录：头像（没有可用头像时用名称首字）和名称，展开后显示角色和「退出登录」。
  - 仅管理员额外显示「后台管理」。

窄屏（约 980px 以下）中间导航和右侧操作收进汉堡菜单。键盘可聚焦，焦点有可见轮廓。系统开启「减少动态效果」时，悬停位移动画关闭。

「管理员」「退出」不作为两个长期占据导航栏的独立文字按钮。

### 3.2 前台路由

| 路径 | 页面 | 谁可以访问 |
| --- | --- | --- |
| `/` | 首页 | 所有人 |
| `/articles` | 文章列表 | 所有人，只含公开文章 |
| `/article/{id}` | 文章详情 | 公开文章所有人可见；私密文章仅管理员打开时可见 |
| `/messages` | 留言板 | 所有人，按可见性规则过滤 |
| `/diaries` | 日记列表 | 所有人，列出全部日记 |
| `/links` | 友情链接 | 所有人 |
| `/about` | 关于 | 所有人，内容来自设置 |
| `/login` | 前台登录 | 所有人 |
| `/register` | 注册 | 所有人；关闭注册后不能提交 |
| `/reset` | 重置密码 | 所有人，需用户名与手机号匹配 |
| `/captcha` | 验证码图片 | 所有人 |
| `/logout` | 退出，仅 POST | 已登录用户 |

### 3.3 后台路由

`/admin/**` 由拦截器保护，登录页 `/admin/login` 除外。

- 未登录访问后台：跳到 `/admin/login`。
- 已登录但不是管理员：跳到 `/admin/login?denied=1`，提示「当前账号没有后台权限」。
- 前端隐藏菜单不能代替这次校验。

| 路径 | 功能 |
| --- | --- |
| `/admin` | 信息总览 |
| `/admin/articles` | 文章列表、公开/私密、热门、删除 |
| `/admin/articles/edit` | 新建或编辑文章 |
| `/admin/categories` | 栏目与标签 |
| `/admin/comments` | 评论审核 |
| `/admin/messages` | 留言审核、回复、删除 |
| `/admin/diaries` | 日记维护 |
| `/admin/notices` | 公告维护 |
| `/admin/links` | 友链维护 |
| `/admin/users` | 用户、锁定、角色 |
| `/admin/logs` | 登录日志 |
| `/admin/settings` | 站点设置 |
| `/admin/profile` | 昵称、手机、头像、修改密码 |

后台侧栏顺序：总览、文章、公告、评论、留言、日记、栏目、友链、用户、登录日志、设置、个人信息。右上角可回前台或退出。退出后回到后台登录页。

## 4. 首页

### 4.1 目标

首页是产品门户，用来说明这个空间做什么，并把人带到已经存在的内容。不堆统计数字，不展示虚构文章。

### 4.2 首屏

- 主标题两行：「让工作更智能，」「让每一天更有序。」第二行使用品牌紫色 `#6658E8`。
- 副标题：「一个融合智能管理、知识沉淀与日常记录的数字工作空间，让信息更有序，让工作更高效。」宽度受限制，不铺满整行。
- 主按钮「探索工作台」：
  - 管理员：进入 `/admin`。
  - 其他人：滚动到本页功能区 `#features`。因为没有公开工作台页面。
- 次按钮「浏览最新文章」：进入 `/articles`。
- 背景是低对比度的淡紫蓝光斑和淡网格，不使用大面积高饱和渐变。

### 4.3 功能卡片

桌面四列，中等宽度两列，手机单列。卡片白底、细边框、圆角约 16px。悬停上移约 3px，过渡约 200ms。整张卡片可点击。

| 卡片 | 谁能看到 | 去向 | 说明 |
| --- | --- | --- | --- |
| 知识与博客 | 所有人 | `/articles` | 记录经验，持续积累 |
| 日记 | 所有人 | `/diaries` | 回顾每天的进展 |
| 留言 | 所有人 | `/messages` | 把想法留在这里 |
| 业务工作台 | 仅管理员 | `/admin` | 集中管理日常事务 |
| 友情链接 | 非管理员 | `/links` | 与「业务工作台」二选一，保证始终四张 |

### 4.4 最近更新

标题右侧「查看全部」进入 `/articles`。

数据一次取完，不重复请求：

| 区域 | 数据 | 条数 | 规则 |
| --- | --- | --- | --- |
| 左侧文章 | 公开文章 | 4 | `isOpen = 1`，热门优先，再按发布时间、编号倒序 |
| 右侧公告 | 公告 | 3 | 置顶优先，再按编号倒序。无详情页，不可点进虚构页面 |
| 右侧日记 | 日记 | 3 | 按创建时间、编号倒序。点击进入 `/diaries` |

每条文章展示：分类首字或封面、标题、摘要、分类名、日期。点击进入 `/article/{id}`。

空数据展示文案，不编造内容。数据库查询失败时显示「最近更新暂时没有加载出来」，并提供重新加载。

### 4.5 页脚

全站前台共用：

- 产品名和一句简介。
- 关于本站 → `/about`。
- 友情链接 → `/links`。
- 版权年份和「智序」。
- 设置项 `footer` 有内容时显示原文。
- `beian`、`icp` 有内容时才显示，没有则留空，不写假备案号。

不重复整条主导航。

## 5. 博客与文章

### 5.1 列表 `/articles`

- 只显示公开文章。
- 每页条数来自设置 `page_size`，默认 6，允许 1 到 50。非法值按 6 处理。
- 排序：热门优先，然后发布时间，然后文章编号，都是新的在前。
- 可按栏目 `cid`、标签 `tag`、关键词 `q` 筛选。关键词匹配标题、摘要、正文。
- 侧栏展示栏目及该栏目公开文章数、标签、热门文章。
- 列表项展示栏目、日期、是否热门、阅读分钟数；`show_visit` 不为 `0` 时显示阅读次数。
- 无结果时显示「没有找到文章。」

### 5.2 详情 `/article/{id}`

- 文章不存在：提示「文章不存在」。
- 私密文章：非管理员看到「这篇文章还没有公开」。管理员可以打开，且不增加阅读数。
- 公开文章每打开一次，阅读数加 1。
- 正文按 Markdown 渲染，并转义原始 HTML，避免把正文当成可执行页面。支持表格扩展。
- 展示关键词、相关阅读、点赞和评论。

### 5.3 写作规则（后台）

保存文章时：

- 标题、正文、栏目必填。栏目必须真实存在。
- 标题最长 255 字。标签串最长 255 字。
- 未填摘要时，从正文生成不超过 140 字的纯文本摘要。
- 公开状态：传入 `0` 为私密，其他情况为公开。
- 热门：传入 `1` 为热门，否则为普通。
- 新建时记录作者、阅读数 0、点赞数 0、创建时间。
- 修改时更新修改时间。新封面上传成功才替换旧封面。
- 封面和头像只接受 jpg、jpeg、png、gif、webp。

列表页可以单独切换公开/私密、设为或取消热门、删除。删除后文章不可再访问。后台列表每页 10 条，可按标题搜索，包含私密文章。

### 5.4 点赞

- 仅对公开文章生效。
- 同一会话对同一篇文章只能点一次。重复点击提示「这篇已经点过赞了」。
- 点赞数保存在文章上，不按用户记流水。

### 5.5 评论

- 站点开关 `allow_comment = 0` 时，前台不能发表评论，并提示「评论已关闭」。
- 评论长度 1 到 1000 字。
- 已登录用户优先用昵称，没有昵称则用用户名。未登录必须填写 1 到 32 字昵称。
- `comment_audit = 1` 时，新评论状态为待审 `0`，前台不显示，提示等待审核。
- 关闭审核时，评论直接通过 `1`，并把文章标记为「已被评论」。
- 前台只显示已通过评论。
- 后台可按状态筛选、通过、隐藏或删除。通过后文章标记为已被评论。后台每页 12 条。

## 6. 留言

### 6.1 前台留言板

- 每页 8 条主留言，按编号新的在前。页码超出时回到最后一页。
- 回复挂在主留言下面。回复另一条回复时，仍然归到最上层主留言，不无限嵌套。
- 被驳回的留言不能作为回复目标。

可见性：

| 观看者 | 能看到的留言 |
| --- | --- |
| 访客 | 仅已通过 `1` |
| 普通用户 | 已通过的，加上自己仍在待审 `0` 的 |
| 管理员 | 已通过的，加上全部待审的 |
| 任何人 | 驳回 `2` 的不在前台出现 |

待审留言在前台带有等待审核的标记，避免作者以为没发出去。

### 6.2 发表

- `allow_comment = 0` 时留言也关闭。
- 未登录必须通过验证码。已登录不需要验证码。
- 昵称 1 到 16 个字。正文 1 到 500 个字。
- 内容不能包含网址，也不能包含「赌博、色情、裸聊、发票、办证、刷单、代孕」。
- 同一 IP 30 秒内不能连续发表，提示「提交太频繁，请稍后再试」。
- 默认进入待审。管理员发表且 `admin_message_pass` 不为 `0` 时直接通过。
- 成功后分别提示「等待管理员审核」或「留言已发布」。

### 6.3 删除

- 登录用户可以删除自己的留言。
- 管理员可以删除任意留言。
- 其他人得到「只能删除自己的留言」。
- 删除主留言时，其回复一并删除。

### 6.4 后台

- 每页 12 条，可按待审、通过、驳回筛选。
- 可通过或驳回。回复保存后，该留言同时变为已通过。
- 待审数量大于 0 时，侧栏留言入口显示红点。

## 7. 日记、公告、友链、关于

### 7.1 日记

- 字段：标题、正文、心情、创建时间。
- 标题最长 100 字，正文最长 2000 字，心情最长 20 字。标题和正文必填。
- 可选心情：随记、开工、想走、读完、高兴、发呆。心情不是必填。
- **没有私密字段。** 保存后的日记会出现在前台 `/diaries` 和首页最近日记中。
- 前台按时间线展示全文，没有单独详情页。
- 后台可新建、修改、删除。

### 7.2 公告

- 字段：标题、正文、是否置顶、创建时间。
- 标题最长 100 字，正文最长 2000 字，两者必填。
- 置顶值为 `1` 或 `0`。
- 首页最多展示 3 条，置顶在前。
- 没有公告详情页，首页只展示标题、摘要和时间。
- 后台可新建、修改、删除。

### 7.3 友链

- 前台以卡片展示名称、描述、地址，新窗口打开，并带 `noopener noreferrer`。
- 排序：排序值升序，再按编号升序。
- 后台校验：
  - 站点名 1 到 15 字。
  - 地址 1 到 45 字，且必须以 `http://` 或 `https://` 开头。
  - 描述 1 到 45 字。
  - 未填排序时按 0。
- 没有友链时前台显示「还没有友链。」

### 7.4 关于

内容完全来自设置项 `about`，按原文换行显示。后台「关于 / 阅读说明」即这一段文字。

## 8. 阅读辅助（现有智能能力）

这些能力附着在文章上，不是一个可对话的助手。

| 能力 | 规则 |
| --- | --- |
| Markdown 渲染 | 正文转成 HTML。原始 HTML 转义，链接做安全处理。支持表格。 |
| 自动摘要 | 未手写摘要时，取纯文本前 140 字，超出加省略号。 |
| 阅读时长 | 约 400 字 1 分钟，不足 1 分钟按 1 分钟。 |
| 关键词 | 先匹配标签词典里出现在标题或正文中的词，再补文章标签；不足时从正文里取高频片段。最多 6 个。 |
| 相关阅读 | 只从其他公开文章里取候选，最多比较 30 篇，展示 4 篇。同一标签每个加 5 分，同一栏目加 3 分，热门加 1 分，分数相同再比阅读量。 |

停用词会从关键词里去掉，避免「我们」「这个」一类词占据结果。

## 9. 账号、权限与安全

### 9.1 注册

- 受 `allow_register` 控制，默认开放。关闭后页面说明注册已关闭，提交也被拒绝。
- 用户名 2 到 32 个字符，不可重复。
- 密码 6 到 32 个字符，保存为 MD5。
- 昵称可空，空则等于用户名，最长 32。
- 手机号可空；填写则必须是 11 位数字。
- 新用户角色固定为普通用户 `1`，状态为正常 `1`。
- 必须通过验证码。

### 9.2 登录

前台 `/login` 和后台 `/admin/login` 分开。后台登录额外要求管理员身份。

失败原因包括：

- 验证码错误。
- 账号或密码错误。不区分具体是哪一个。
- 账号已锁定。
- 后台登录时没有后台权限。

成功后：

- 更换会话标识，再写入登录用户。
- 更新最近登录时间、登录 IP、登录次数。
- 前台登录回到首页，后台登录进入 `/admin`。
- 写一条登录日志，成功和失败都记。日志含用户、IP、是否成功、原因、时间。

验证码为 4 位，字符集去掉容易混淆的字符，不区分大小写，使用一次后失效，图片禁止缓存。

### 9.3 重置密码

提供用户名、注册时留下的手机号、新密码和验证码。用户不存在，或手机号为空、不匹配，都拒绝。新密码至少 6 位。

### 9.4 退出

仅接受 POST。会话作废。若带有站内相对路径 `next`，则回到该路径；拒绝以 `//` 开头的地址，避免跳到站外。前台退出回首页，后台退出回后台登录页。

### 9.5 角色与锁定

| 字段 | 取值 | 含义 |
| --- | --- | --- |
| `role` | `0` | 管理员 |
| `role` | `1` | 普通用户 |
| `state` | `0` | 锁定，不能登录 |
| `state` | `1` | 正常 |

补充规则：

- 用户名 `admin` 即使角色不是 `0`，也视为管理员，且不能被改角色。
- 不能锁定自己，不能修改自己的角色。
- 管理员可在后台修改他人角色和锁定状态。
- 普通用户访问任何 `/admin/**` 都会被拦截。

### 9.6 个人资料

管理员可在后台修改：

- 昵称，最长 32。
- 手机号，空或 11 位数字。
- 头像图片。上传成功后地址为 `/uploads/{随机文件名}`。
- 密码。必须验证原密码，新密码至少 6 位。

前台头像只在图片地址可用时显示。含 `localhost` 或反斜杠的旧地址视为无效，改用首字。

## 11. 站点设置

| 键 | 含义 | 约束 |
| --- | --- | --- |
| `site_name` | 站点名 | 最长 40。前台品牌固定显示「智序 · Smart ERP」，此值仍保留给设置和登录页 |
| `site_subtitle` | 副标题 | 最长 80。首页主标题已改为固定文案，此项仍可在后台维护 |
| `footer` | 页脚补充文字 | 最长 80。有内容才显示 |
| `about` | 关于 / 阅读说明 | 前台关于页原文展示 |
| `page_size` | 前台文章每页条数 | 数字，默认 6 |
| `show_visit` | 是否显示阅读量 | 不为 `0` 时显示 |
| `allow_comment` | 允许评论和留言 | `0` 关闭 |
| `comment_audit` | 评论先审后发 | `1` 开启 |
| `admin_message_pass` | 管理员留言免审核 | 不为 `0` 时免审 |
| `allow_register` | 开放注册 | 不为 `0` 时开放 |
| `beian` / `icp` | 备案文字 | 没有配置界面。键存在且非空才在页脚显示 |

首次启动若这些键不存在，会写入默认值。已有值不会被覆盖。留言表若缺少 `uid`、`ip`、`parent_id` 列，启动时补列。

若库里还没有日记，会写入两条示例日记；还没有公告，会写入一条置顶公告。已有数据不重复插入。

## 12. 栏目与标签

- 栏目名 1 到 30 字，不能重名。
- 栏目下仍有文章时不能删除。删除栏目时，其下标签一并删除。
- 标签必须属于一个已存在的栏目，名称 1 到 30 字。
- 文章上的标签以文本保存，前台可按标签筛选。
- 前台栏目说明对「运动、旅游、购物、编程」有固定短句，其他栏目使用通用说明。

## 13. 界面与交互要求

### 13.1 前台视觉

- 背景以白和浅灰为主，正文深灰蓝 `#1c2433`。
- 品牌色 `#6658E8`，按下或悬停的深色为 `#5146C4`。
- 内容宽度最大约 1200px，两侧留白。
- 卡片细边框、轻阴影、约 16px 圆角。
- 按钮主次分明：主按钮实心紫色，次按钮白底描边。
- 不使用大面积霓虹、玻璃拟态堆叠和装饰性统计数字。

### 13.2 交互

- 导航激活态与当前路由一致。
- 链接、按钮、菜单在键盘聚焦时有可见焦点。
- 前台页面使用语义化的页眉、导航、主内容、页脚和标题层级。
- 图片地址不可用时不显示破图。
- 业务失败用页面内提示，不跳到空白错误。业务异常页提供回首页。

### 13.3 后台视觉

后台保持现有管理工作台布局：左侧菜单、右侧内容、顶部当前用户与退出。本次门户改版不改变后台业务页面的信息结构。

## 15. 异常与空状态

| 场景 | 表现 |
| --- | --- |
| 没有公开文章 | 首页和列表给出空文案 |
| 没有日记、公告、友链、评论 | 各自页面给出空文案 |
| 首页内容查询失败 | 错误说明 + 重新加载 |
| 文章不存在或未公开 | 错误说明 |
| 验证码、登录、注册、评论、留言校验失败 | 停留当前流程并显示原因 |
| 无权限访问后台 | 回到后台登录，并说明没有权限 |
| 其他业务异常 | 统一错误页，可回首页 |

## 16. 非功能需求

- 页面为服务端渲染。首页不为了展示再发一套重复接口。
- 后台权限在服务端拦截，不依赖前端隐藏。
- 文章正文渲染时转义 HTML。
- 退出跳转只允许站内相对路径。
- 验证码一次一用。登录成功后更换会话标识。
- 上传限制图片类型和大小。
- 留言有 IP 频率限制和禁用词。
- 前台适配桌面、平板和手机，导航在窄屏收起，页面不出现横向滚动。
- 动效约 180–250ms，并服从系统的减少动态效果设置。

## 17. 验收要点

1. 访客可以浏览首页、公开文章、日记、友链、关于，并在验证码通过后留言。
2. 私密文章、待审评论、驳回留言不会出现在访客可见列表。
3. 普通用户登录后不能打开后台页面。
4. 管理员可以从导航进入后台，并完成文章、评论、留言、日记、公告、友链、栏目、用户和设置的现有操作。
5. 退出后会话失效，受保护页面不可再直接使用。
6. 首页按钮和导航都指向真实路由；没有助手页面、没有计划模块、没有日记隐私开关。
7. 首页文章、日记、公告来自数据库；没有数据时看到空状态。
8. 桌面与手机宽度下导航不重叠、页面不横向溢出。
